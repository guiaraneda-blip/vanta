# Vanta OS
### A cybersecurity-focused Linux distribution built for pentesters who are just getting started.

> "Lo ve todo. No lo ve nadie."

---

## What is Vanta?

Vanta is a Debian-based Linux distribution designed for penetration testing and ethical hacking. Unlike other security distros that overwhelm users with hundreds of tools, Vanta focuses on a curated, guided workflow — powered by SPECTR as its core engine.

Built by a cybersecurity student, for cybersecurity students.

---

## Why Vanta over Kali?

| | Kali Linux | Vanta OS |
|---|---|---|
| Tools | 600+ preinstalled | Curated essentials |
| Target user | Advanced professionals | Beginners → Advanced |
| Core engine | None | SPECTR (built-in) |
| Language | English only | Spanish + English |
| Philosophy | Tools first | Workflow first |
